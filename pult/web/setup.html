Сертификат Пульта

Эту страницу откройте сначала по обычному адресу из консоли, http://адрес-компьютера:4721/setup. Safari откроет её до доверия сертификату. По этому HTTP доступны только профиль и проверка /ping. Файлы и управление идут по HTTPS после доверия.

  1. Скачайте профиль и сверьте имя с окном агента на компьютере.
  2. На iPhone: Настройки → Основные → VPN и управление устройством → Пульт → Установить.
  3. Включите доверие: Настройки → Основные → Об этом устройстве → Доверие сертификатам.
  4. Вернитесь на страницу Пульта и введите шестизначный код с компьютера.

Профиль содержит только сертификат, без VPN. В интернет этот адрес выставлять не нужно.
