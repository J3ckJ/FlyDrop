    Первое подключение iPhone: настройка HTTPS

    Для Safari один раз установите сертификат вашего Windows. Переключите QR-код на «Настройка HTTPS» в карточке подключения. Страница настройки содержит только инструкцию и публичный сертификат; файлы и текст по HTTP не передаются.

    SHA-256 публичного сертификата:

    Сверьте сертификат с компьютером до включения доверия. Если Safari показывает предупреждение, проверьте настройки сертификата; обходить его не нужно.

    Разрешённые устройства

    Доверенные устройства запоминаются на 30 дней, разовые — до конца сеанса. Отзыв доступа завершает подключение и удаляет связанные временные файлы.

    Пока нет разрешённых устройств. После сканирования подтвердите подключение здесь.

    Диагностика соединения

      При проблемах разрешите FlyDrop в брандмауэре для частной сети. Порты: HTTP 4317 для инструкции и HTTPS 4318 для передачи. VPN и изоляция клиентов в роутере могут мешать соединению.

      Windows-приложение

      Ctrl+Shift+Space — открыть текст, файлы или снимок из буфера. Ctrl+Shift+Enter — отправить буфер выбранному получателю. Каждая папка упаковывается в отдельный zip. Автоматической отправки без нажатия нет.

      Компьютер подтвердил это подключение. Доступ можно отозвать на Windows. FlyDrop не читает буфер в фоне и не отправляет содержимое автоматически.

      Как это работает

      Windows и iPhone в одной Wi-Fi сети. Файлы и текст идут через ваш компьютер, без облака.
