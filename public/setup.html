FlyDrop

Защищённая связь.
Один раз настроим.

Для локального HTTPS на iPhone нужен публичный сертификат вашего компьютера. Этот профиль не добавляет VPN, аккаунты и управление устройством.

  1. Проверьте сертификат на Windows

    В разделе «Безопасность» показаны имя и SHA-256 сертификата. Устанавливайте профиль только из своей домашней сети, сверив сертификат с компьютером. Страница загрузки по HTTP сама по себе не защищает от подмены.

  2. Загрузите профиль

    Загрузить FlyDrop.mobileconfig

  3. Установите его в настройках iPhone

    Настройки → Основные → VPN и управление устройством → загруженный профиль FlyDrop → Установить.

  4. Включите доверие вручную

    Настройки → Основные → Об этом устройстве → Доверие сертификатам → включите сертификат FlyDrop Local.

  5. Откройте защищённую ссылку

    На Windows переключите QR-код на «Подключение» и отсканируйте его. Ссылка должна начинаться с https://. Если Safari показывает предупреждение сертификата, остановитесь и проверьте настройки; обход предупреждения не нужен.

Далее подтвердите устройство на Windows. Чтобы добавить FlyDrop как приложение: в Safari нажмите «Поделиться» → «На экран Домой» → «Добавить».

Профиль можно удалить через «VPN и управление устройством». При смене сетевого адреса компьютера может потребоваться новая ссылка и новый ярлык.
