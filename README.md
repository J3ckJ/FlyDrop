# FlyDrop

Файлы и текст между Windows и iPhone. Одна Wi-Fi сеть, без облака.

Windows работает как отдельное приложение. iPhone открывает FlyDrop в Safari или с иконки на экране «Домой». Всё проходит через ваш компьютер: после установки интернет не нужен.

> Local file and text sharing between a Windows PC and an iPhone on the same Wi-Fi. No cloud, no account.

## Четыре раздела

Слева — настоящее меню, а не прокрутка одной длинной страницы.

| | Раздел | Что внутри |
|---|---|---|
| 1 | **Передача** | Получатель, файлы или текст, QR-код второго устройства |
| 2 | **Входящие** | То, что пришло на это устройство, и то, что уже отправлено |
| 3 | **Безопасность** | Код подключения, доверенные устройства, папка, автозапуск |
| 4 | **Как это работает** | Короткая схема: сеть, QR, обмен в обе стороны |

Запрос нового устройства остаётся наверху на любом разделе: код видно сразу, не нужно искать его внизу страницы. Кнопка **EN / RU** в шапке переключает язык и запоминает выбор.

## Как открыть на Windows

Готовый файл — `FlyDrop-0.3.0-Windows.exe`. Node.js на этом компьютере не нужен.

Окно закрывается в трей. Полностью выйти можно только через **«Выход»** в меню трея. Автозапуск лучше включать уже после того, как `.exe` лежит в постоянной папке: при переносе файла включите автозапуск заново.

При первом запуске Windows показывает шаги: общая сеть, сертификат, ручное доверие на iPhone, защищённая ссылка и код. Экран не ставит сертификат сам и не просит обходить предупреждение Safari. «К передаче» или «Настрою позже» скрывают его; QR в разделе «Передача» остаётся.

Простое открытие `localhost` в браузере не даёт управления. Ссылку для браузера на этом же компьютере выдаёт пункт трея **«Открыть в браузере»**: она одноразовая и живёт две минуты.

## iPhone: один раз настроить HTTPS

Оба устройства должны быть в одной сети, которой вы доверяете. На Windows в списке адресов выбирайте обычный адаптер. VPN и виртуальные адаптеры подписаны отдельно.

1. В карточке подключения переключите QR на **«Настройка HTTPS»** и откройте его камерой в Safari. Эта страница по HTTP отдаёт только инструкцию и публичный сертификат. Файлы и текст по HTTP из локальной сети не передаются.
2. Сверьте имя и SHA-256 с разделом **«Безопасность»** на Windows. Если сверить не получается, доверие включать не нужно: первую загрузку по HTTP теоретически можно подменить. Профиль содержит только сертификат, без VPN и MDM.
3. Установите профиль: **Настройки → Основные → VPN и управление устройством → FlyDrop → Установить**.
4. Включите доверие вручную: **Настройки → Основные → Об этом устройстве → Доверие сертификатам → FlyDrop Local**. [Инструкция Apple](https://support.apple.com/ru-ru/102390).
5. Верните QR на **«Подключение»** и откройте `https://…:4318`. Если Safari предупреждает, проверьте адрес и сертификат. Обходить предупреждение не нужно.
6. На обоих экранах появится код. На Windows нажмите **«Разрешить»**. До этого iPhone не видит входящие и ничего не отправляет. Устройство можно запомнить на 30 дней или пустить один раз.

Сертификат свой у каждой установки. В него входят только localhost и частные IPv4-адреса. Закрытый ключ лежит в `%APPDATA%\FlyDrop\security\vault.safe` и закрыт Windows DPAPI. В доверенные корневые Windows он сам не ставится. На iPhone профиль удаляется в тех же настройках.

Чтобы открывать FlyDrop как приложение, в Safari на уже защищённой странице: **«Поделиться» → «На экран Домой» → «Добавить»**. Если отдельное окно не подхватило сеанс Safari, введите шестизначный код с компьютера и подтвердите запрос ещё раз. Лишнее подключение можно отозвать.

Без компьютера на экране будет «Нет связи». Передача возможна, только пока Windows-приложение запущено и оба устройства в одной сети. Смена IP — перезапуск FlyDrop и новый QR.

## Горячие клавиши

Буфер читается только в момент нажатия. Фоновой отправки нет, и получателя приложение само не выбирает.

| Сочетание | Действие |
|---|---|
| **Ctrl+Shift+Space** | Открыть «Передачу» и подставить текст, файлы или снимок из буфера |
| **Ctrl+Shift+Enter** | Сразу отправить буфер последнему выбранному получателю, если он сейчас на связи |
| **Ctrl+Enter** | Отправить то, что уже набрано или выбрано в окне |

Файл из Проводника уходит файлом, а не строкой с путём. Каждая папка становится отдельным zip. Снимок **Win+Shift+S** уходит как PNG или JPEG. Если сочетание занято другой программой, остаётся меню трея.

## Передача

- Файл до 1 ГБ. Во временной папке — до 2 ГБ, не больше 500 файлов и трёх загрузок сразу.
- Текст до 50 000 символов.
- Входящие живут час и лежат в своём разделе. История не пишется на диск и пропадает при выходе.
- Картинки PNG, JPEG и WebP до 20 МБ можно посмотреть во входящих. HTML и SVG как страница не открываются.
- «Сохранять входящие файлы в выбранную папку» выключено, пока вы сами его не включите. Уже существующий файл не перезаписывается: к имени добавляется номер.
- Уведомление Windows говорит, что файл пришёл, и не показывает текст заметки.

Отзыв доступа закрывает сеанс и удаляет временные файлы на компьютере. Копию, которую получатель уже сохранил у себя, отозвать нельзя.

## Если не соединяется

Проверьте общую сеть, что приложение открыто, что выбран обычный адаптер и что код ещё не истёк. Новый код и QR сбрасывают ожидающие запросы; уже разрешённые устройства остаются, пока их не отозвать.

Порт **4317** — страница настройки. Порт **4318** — сама передача. Если брандмауэр спрашивает разрешение, дайте его только частной сети. Гостевой Wi-Fi с изоляцией клиентов и VPN часто мешают. FlyDrop сам порты не открывает и правила брандмауэра не меняет. В интернет эти порты выставлять не нужно.

## Сборка

Для разработки нужен Node.js 22 или новее. Готовому `.exe` он не нужен.

```powershell
npm.cmd ci
npm.cmd start
npm.cmd test
npm.cmd run desktop:smoke
npm.cmd run build:win
```

Сборщик кладёт portable-файл в `release\`. За корпоративным TLS-прокси для Node можно включить системное хранилище: `$env:NODE_USE_SYSTEM_CA = '1'`. Проверка сертификатов при этом остаётся включённой.

`node server.js` без Electron не умеет защищённое хранилище. Запускайте через `npm.cmd start`.

Это локальный обмен в вашей сети, не AirDrop: нет Bluetooth, интернета и подписи издателя Windows. Независимого аудита у сборки нет.
